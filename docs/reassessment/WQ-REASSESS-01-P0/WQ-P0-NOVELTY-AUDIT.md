## Classification vocabulary

- `COMMODITY` — widely available mechanic; not a reason to choose WildQuest.
- `CROWDED` — common in direct competitors and risky as primary positioning.
- `DIFFERENTIATED` — materially different implementation or user value.
- `POTENTIAL_WEDGE` — could become distinctive if productized further.
- `UNVERIFIED` — insufficient public evidence.
