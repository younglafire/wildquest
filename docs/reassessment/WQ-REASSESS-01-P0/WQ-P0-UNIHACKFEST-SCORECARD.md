# WQ-P0 UniHackFest Scorecard

## Purpose

Map exact repository evidence to the UniHackFest 2026 judging model. Scores are provisional until every band is grounded in implementation, product, market, or competition evidence.

## Scoring rules

For every criterion record:

- current evidence;
- current weakness;
- score with uncertainty;
- ceiling if no pivot occurs;
- specific action required to improve it.

Do not award points for planned features or unsupported claims.
